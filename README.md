# 悬浮方舟 · No.07 — 玻璃立方微缩生态

一个悬浮在深空中的透明玻璃立方体，内部封存着一方完整世界：
雪山、蜿蜒河流与瀑布、针叶森林、草甸野花、小湖泊，以及在其中生活的鹿、
飞鸟、蝴蝶、兔子、水鸭与锦鲤。柔和的昼夜循环、云朵与薄雾、体积光、
夜晚的萤火虫与夜光蘑菇，配合移轴虚化的微距摄影质感。

纯 Three.js 单文件实现，无构建步骤。

## 在线预览

**https://lzllzllzllzllzl.github.io/glass-cube-terrarium/**

## 本地运行

页面需从 CDN 加载 three.js，请保持网络畅通：

```bash
# 方式一：直接双击打开 index.html
# 方式二：本地服务器
python -m http.server 8080
# 打开 http://localhost:8080
```

## 操作

- **拖动** 旋转视角（缓慢自动旋转，交互后暂停片刻）
- **滚轮** 推近 / 拉远
- **双击** 复位等距视角
- 右上角按钮：暂停昼夜循环、调整时间流速

## URL 参数

| 参数 | 说明 |
| --- | --- |
| `?t=0.30` | 一天中的时刻（0–1，0.25≈正午，0.75≈午夜） |
| `?speed=2` | 昼夜流速倍率（默认 ×1，一昼夜 96 秒） |

## 实现要点

- **地形**：程序化噪声高度场（雪山 + 断崖台地 + 湖盆 + 河道下切距离场），
  顶点着色的黏土质感，玻璃内侧可见剖面土层
- **水体**：自定义 GLSL 着色器——河道流向条纹 / 陡滩泡沫 / 湖面涟漪与星光闪烁，
  瀑布为独立滚动着色器 + 底部水雾粒子
- **生态**：实例化松林 / 草丛 / 野花 / 岩石，程序化低多边形动物（鹿、兔、鸭、
  鸟、蝴蝶、锦鲤），全部沿曲线巡游并带步态动画
- **昼夜系统**：太阳/月亮沿倾斜轨道运行，晨光、白昼、暮色、夜晚四相平滑过渡；
  星空、星云、萤火虫、夜光蘑菇、玻璃棱线辉光随相位联动
- **后期**：UnrealBloom 辉光 + 自定义移轴（tilt-shift）着色器
  （主体清晰、边缘与深空虚化、暗角、色差、胶片颗粒）
- **玻璃立方**：`MeshPhysicalMaterial` transmission 折射 + 菲涅尔边缘微光 +
  金属边框与角标 + 底部悬浮铭牌与光晕，四周环绕浮空碎岛
